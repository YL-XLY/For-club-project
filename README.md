# 📚 课程表小工具

这是一个使用 **HTML + CSS** 编写的个人课程表网页小工具。

## ✨ 功能

- 以表格形式展示每周课程安排（周一至周日）
- 支持 1-12 节课的完整时间范围
- 使用了我喜欢的蓝色
- 纯前端实现，无需任何依赖，浏览器直接打开即可使用

## 🛠️ 技术栈

- HTML5
- CSS3

## 🚀 使用方式

直接在浏览器中打开 `index.html` 文件即可查看课程表。

(因为本人才初学C语言，所以代码什么的几乎都是agent生成的qwq）本项目由 **AI 辅助生成**，是一个简单的课程表展示工具。如需修改课程信息，直接编辑 `index.html` 中的表格内容即可。
